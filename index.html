        Como usar o modo de voz do Claude
        
        
          
          
        1. Na Fluente, escolhe o tipo de conversa e toca em Copiar e abrir o Claude.
          2. 
          
        2. Na app do Claude, numa conversa nova, cola a mensagem e envia. O Claude responde com a primeira pergunta.
          3. 
          
        3. Toca no botão de voz (ao lado do campo de texto). A partir daqui é só falar. Podes interromper o Claude a meio.
          4. 
          
        4. Quando quiseres acabar, diz “end session” e sai do modo de voz. O relatório aparece por escrito.
          5. 
          
        5. Copia a resposta (mantém o dedo em cima dela → Copiar) e cola-a no passo 4 da Fluente.
          6. 
        
        
        
        Nas definições da app do Claude podes escolher a voz. As vozes britânicas e americanas servem as duas: o importante é ouvires muito.

        Como ligar ao GitHub
        
        
        Se já tens um token para outra app (Caderno, Horta, Cozinha, Descomplica), podes acrescentar-lhe este repositório em vez de criar outro:
        
        
          
          
        1. Abre github.com/settings/personal-access-tokens.
          2. 
          
        2. Abre o token que já usas e carrega em Edit. Em Repository access, acrescenta fluente-dados e guarda. Depois toca em Usar o token de outra app.
          3. 
          
        3. Ou cria um novo: Generate new token, Only select repositories → fluente-dados, e em Repository permissions → Contents escolhe Read and write. Cola-o abaixo.
          4.
